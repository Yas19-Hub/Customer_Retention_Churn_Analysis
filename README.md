## 📌 Project Overview

This project analyzes customer retention and churn using the RavenStack SaaS dataset. The dashboard provides insights into customer behavior, subscription revenue, churn reasons, support performance, and feature usage using Python and Power BI.

## 🎯 Objectives

- Analyze customer churn
- Monitor subscription revenue
- Identify top churn reasons
- Evaluate support performance
- Analyze feature usage
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies
- 🐍 Python
- 📊 Power BI

- 🔢 NumPy
- 📉 Matplotlib
- 💻 VS Code
- 🌐 GitHub

## 📂 Dataset

The RavenStack SaaS dataset consists of:

- Accounts
- Subscriptions
- Feature Usage
- Support Tickets
- Churn Events

## 📈 Business Insights

- Enterprise plan generates the highest Monthly Recurring Revenue.
- Overall churn rate is approximately 22%.
- Feature-related issues are among the leading churn reasons.
- DevTools and FinTech have a strong customer presence.
- Support tickets are distributed across all priority levels.
- Feature usage highlights the platform's most valuable capabilities.
